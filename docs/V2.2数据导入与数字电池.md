# GeoCIM V2.2：数据目录、平面底图与数字电池

更新日期：2026-09-21。主入口：https://geocimplus.com/ ，兼容入口：https://geocimplus.com/v2.html 。代码在 `D:\GeoCIM_Demo`，分支 `codex/v2`。本次延续 V2.2，工具组的全面重排留到 V3。

## 使用

1. 首页三类示例为城市更新、城市交通、数字孪生。城市更新卡片下介绍沙头项目；交通与校园示例仍为后续开发。
2. 新建项目后，打开“上传”，选择分析 / 展示 / 结果母图层，点击“选择本地文件”。在弹出的数据目录里浏览文件夹，或者选择数据和配套文件。
3. 数据目录按实际 SHP 文件头及 GeoJSON 几何识别点、线、面；GeoTIFF 显示栅格尺寸、坐标系。Shapefile 的 shp/shx/dbf/prj/cpg 合并成一行，同名但不同文件夹的数据保持独立。缺失配套文件会列出，继续添加即可补齐。每一行可以修改数据类别后再导入。
4. Windows 文件选择器里的“AutoCAD 形源”等名称属于系统文件关联，网页不会修改系统设置。数据目录中的“点 / 线 / 面 / 栅格”才是本平台识别出的 GIS 类型。
5. 整个 `TOSHP` 文件夹已实测：边界 1、建筑 5306、路网 124、人口网格 178；三个 `111c*` 目录识别为 ArcInfo Grid 栅格。浏览器暂不直接解码 ADF，需先在 GIS 软件中转为有空间参考的 GeoTIFF。固定示例已有审计后的卫星 GeoTIFF。
6. 从首页重新进入城市更新示例，可看到“展示图层 → 交通 → 路网”和“展示图层 → 底图 → 卫星底图 · 平面参考”。旧 `.geocim` 快照保存的是当时的数据，不会自动加入新增示例图层。
7. 平面卫星底图覆盖原影像范围，位于地形下方，与 DEM 起伏无关，可单独开关。现有来源为第一波段灰度影像，不宣称已确认彩色波段顺序。Rhino ZIP 包含单独的 `08_FlatBaseMap` 图层和 `satellite-flat.png`，地理参考 JSON 记录其参考平面高度。
8. CIRCUIT 菜单、节点、端口和参数跟随中英文切换。添加“数字滑条”电池，从其“数值”输出连接到网格“大小”、缓冲区“距离”或核密度的“带宽 / 网格大小”。可直接拖动数值，也可输入；最小值、最大值、步长在右侧修改。连接的数值优先于节点自己的备用参数。数值不会随拖动自动发起云计算，点击“运行流程”后才执行。

## 数据与计算

- 原始路网：`C:\Users\pc\Desktop\TOSHP\TOSHP\路网.shp` 及配套文件，只读。
- 路网原坐标：EPSG:32649；124 条有效 LineString。CPG 与字段字节确认 UTF-8，转换时显式指定，保留中文道路名和全部属性。
- 示例副本：`data/v2/shatou/roads.geojson`，EPSG:4326；服务器米制分析沿用 EPSG:32650。
- 数据准备：`geocim-dev\Scripts\python.exe scripts\prepare_v2_roads.py`。执行后更新示例 catalog，并输出 `reports/v2.2/roads-audit.json`。完整准备脚本 `prepare_v2_data.py` 也会调用它。源文件哈希前后对照，保证原文件内容不变。
- 固定示例仍由服务器运行白名单计算；新建、导入和修改的数据在浏览器本地处理。服务器拒绝上传数据和非示例来源，数值电池不能绕开网格尺寸限制。本次未接入模型 API。

## 路网薄层更新

路网显示为沿地形三角面铺设的立体薄带：示意宽度 2 米，厚度 0.15 米，底部距地形 0.35 米。宽度和厚度是显示参数，不是实测道路尺寸，不写入原始道路属性或分析数据。路网跨越网格时会按地形三角面分割；无有效高程处留空。材质同时使用轻微深度偏移，减少底图叠加造成的重面闪烁。

保留图层可见性、分类颜色、透明度和选中高亮。Rhino 的 `09_RoadNetwork` 图层输出对应薄层网格，并记录示意尺寸及来源要素；不会再叠加重合的路网中心线。此次源数据未修改。
