# GeoCIM Circuit · 空间电路

历史 V1 说明：当前保留入口为 https://geocimplus.com/v1.html ，主域名已是 V2。版本对比及阅读顺序见 [阅读指南](V1与V2对比及ChatGPT阅读指南.md)。

本版把本地 GIS 操作组织为可连接的电池。顶部「模型建构器 Circuit」打开画布；地图、属性表和基础分析继续可用。沙头分析是默认项目预设；只有导入个人文件后，项目下拉才显示「我的数据」。

## 实际用法

1. 选择「代表点 → 核密度」「高度选择 → 缓冲区」或「字段统计流程」，点击载入预设。
2. 点击输入图层电池，在右侧绑定当前工作空间图层。点击分析电池修改参数。
3. 从左侧添加电池，拖动安排位置。拖动端口连线，或依次点击输出、输入端口；也可以展开右侧「精确连接」按名称选择端点。
4. 选中连线或电池后，用右侧删除按钮移除。每个输入端口只接受一条线，输出可以分支。
5. 点击运行流程。运行记录显示每个电池实际数量；输出电池将矢量结果加入地图，统计结果在右侧下载。流程失败或取消时不发布部分结果。
6. 保存流程会下载 GeoCIM-Circuit.json；打开流程可重新加载布局、连线和参数。文件不包含 GIS 数据。个人图层 ID 是本次浏览器会话 ID，重新导入数据后需要在输入电池中重新绑定。

可用本地电池：输入、按属性选择、代表点、缓冲区、面积与长度、点核密度、字段统计、微流程、结果输出。统计输出只能接结果输出电池；其他分析输入为矢量。核密度的点几何、权重和规模仍由既有分析校验器检查。

模型建构器最多 40 电池、80 连线，每个输入一条线；拒绝循环和未知组件。累计生成结果最多 150 万坐标位置，任务总时限 90 秒，可取消。基础工具本身的要素、带宽、距离与空间范围上限仍然生效。

## 微流程代码示例

选中「微流程」电池，在右侧粘贴以下 JSON，点击应用代码，再连接输入和输出：

```json
[
  {"operation": "centroid"},
  {"operation": "buffer", "distance": 50}
]
```

微流程支持 1–6 步 centroid / buffer / measure / kde，参数与基础分析相同。这是声明式分析配方，不是 JavaScript、Python、Shell 或 SQL 执行器。未来 AI 生成配方后，也必须通过同一套校验再执行。

## 与 GeoCIM 对话和模型连接

分析工作台下拉可切换「基础分析」和「Chat with GeoCIM」。本地预设支持打开属性表、按高度选择建筑、设置建筑透明度、显示人口网格、生成核密度电路；输入「创建缓冲区电路」「统计高度」「2D」「3D」「清除选择」也可执行对应操作。中英文预设均支持。

点击对话框右上角连接图标，或选择「模型 API · 待连接」，显示 OpenAI / DeepSeek 入口与未连接状态。本版按用户“先预留对话框”的要求，没有配置实际 API，也没有建立本站账号登录或计费系统。

OpenAI API 需要服务端 API 凭据；在 ChatGPT 网页登录另一个账号不会自动授权第三方网站。后续可用另一账号对应的 OpenAI Platform 项目配置服务端密钥；需要另行完成 API 访问、预算、本站用户认证、额度和限流，然后才启用公开模型请求。不得把密钥填进对话框、流程文件或前端包。

官方认证说明：https://developers.openai.com/api/reference/overview#authentication

## Food4CIM 扩展约定

界面预留 Food4CIM 分区与 2SFCA、选址决策、批量裁剪组件。本版这些组件仅为规划标记，不能运行。没有上传热舒适数据。

后续组件应提供固定版本的组件标识、输入/输出类型、参数 schema、运行位置（本地 Worker / 经认证的服务端）、授权与费用状态。将操作注册到白名单并实现专用校验后再启用，不能从外部 manifest 直接执行代码。批量任务需要单独加入数据列表端口、逐项状态、取消和部分失败策略；当前单层端口不会伪装成已支持批处理。

目前的集成点：src/circuit.mjs 定义组件、图结构校验和执行；src/spatial.worker.js 分发；src/CircuitBuilder.jsx 编辑 UI；src/chat-commands.mjs 解析本地预设；src/ChatPanel.jsx 是未来模型连接入口。

## 浮动与停靠布局（20260906-201442）

建构器默认停靠在地图下方。拖动窗口上缘调整高度；拖动标题栏移动为浮动窗口，松开时靠近屏幕底部可重新停靠，也可以点击「浮动窗口 / 停靠下方」。浮动模式右下角可调整大小。地图和分析工作台不再被遮罩禁用，运行记录逐步更新，流程成功后结果加入地图。

属性表顶部有拖动条，向下拖可缩小。小于 220 像素时暂时隐藏条件与样式操作区，保留记录表格；向上拉大恢复。支持键盘上下方向键调整这两个高度。

首次访问默认英语；手动选择中文后仍记住偏好。对话名称为「与GeoCIM对话」/「Chat with GeoCIM」。本次不修改分析算法和 API 状态。
