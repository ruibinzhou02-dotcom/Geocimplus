## 建议检查顺序

1. 打开本地 V2，进入沙头示例。用右键旋转、滚轮放大，检查屋顶与立面。
2. 点击 Buildings 子图层，在 Layers 选择 Quantiles，字段选 `BLDG_HEIGH`，查看高度色带。
3. Scene → Raster → fishnet，源选 Land surface temperature，50m，Bilinear，命名后创建。结果出现在 Analysis 主图层。
4. 在结果图层打开属性表，按 `mean_value` 选择要素，导出已选 GeoJSON。可拖动属性表上边缘缩小。
5. Analysis → Create density circuit → Send。打开 CIRCUIT，检查“Vector input → Representative points → Point kernel density → Analysis layer”，然后运行。统计或缓冲等从电池窗口的模板菜单开始。
6. CIRCUIT 保留底部停靠、拖动浮窗、缩放、类型端口、参数、分组/解组、JSON 导入导出。沙盒仍是受限数学表达式电池。
7. 顶部 Plugins 查看 EPW；Upload 中先选类别，再选择 Shapefile 配套文件或 ZIP、GeoJSON、GeoTIFF、EPW。
8. 保存项目，刷新，从首页本地项目列表恢复。也可将下载的 `.geocim` 包移到另一台电脑。

## 计算含义

- 默认网格均值按源像元与目标网格的投影交叠面积加权。`min_value`/`max_value` 是参与计算的有效源像元最值；coverage 是有效面积比例。
- 双线性和最近邻计算目标格中心采样值。此时 `mean_value` 保存中心采样结果，`min_value`/`max_value` 与该结果相同；coverage 为采样支撑是否完整（0/1），不代表面积覆盖率。方法写入结果元数据。
- 双线性不跨越缺失像元、不外推；新网格不能增加原数据的真实分辨率。类别栅格优先用最近邻，连续量可用均值或双线性。
- 分位数遇到大量重复值会合并重复断点；唯一值图例最多单列20类，其余合为 Other / NoData。
- DSM 下建筑地面仍为邻近网格估算，不是实测裸地地形；真实 NoData 边缘仍可出现孔洞、阶梯状边界，不用虚构高程补满。
- 数据树目前是主图层 → 子图层两级结构。电池有类型和分组，尚未实现 Grasshopper 完整 Data Tree 或任意 Python 环境。
