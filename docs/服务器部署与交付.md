## 发布和回滚

当前真实数据版构建：先 `pnpm run build`，再 `geocim-dev\Scripts\python.exe scripts\build_public_analysis.py`。本机网站需运行，以读取选定的范围和影像定位信息；发布白名单文件需位于 private/public-review。脚本每次创建新版本，不覆盖旧包。旧的 build_public_demo.py 仅用于重建历史模拟数据。

每次发布：上传审核后的单独 site.zip 到 admin 家目录；解压到新的 `/www/wwwroot/geocimplus/releases/<版本>`；核对 manifest；记录旧 current 的真实目标；通过临时符号链接与 `mv -Tf` 原子替换 current。配置修改前复制到 `/var/backups/geocim/<时间>/`，始终先 `nginx -t`，成功才 reload。

回滚到本次模拟版（在服务器执行）：

```sh
sudo ln -s /www/wwwroot/geocimplus/releases/20260906-170240 /www/wwwroot/geocimplus/rollback-link
sudo mv -Tf /www/wwwroot/geocimplus/rollback-link /www/wwwroot/geocimplus/current
sudo nginx -t && sudo systemctl reload nginx
```

若 rollback-link 已存在，先核对它的目标再处理，不覆盖未知文件。静态版本回滚无需恢复原始数据。需要暂停本站时，将本站配置移到备份目录并通过语法检查后重载；不要删除版本目录或证书。

仅在确实需要恢复部署前环境时：备份现状、停止系统 nginx、从初始备份恢复对应目录。初始环境没有网站，不要将这种恢复误认为恢复到可访问的旧站。

服务已开启 gzip 压缩；敏感路径测试返回 404/403。浏览器验收截图与汇总位于 `reports/resume_20260906_164140/public-site.png` 和 `acceptance.json`。
