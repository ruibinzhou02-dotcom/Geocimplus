# GeoCIM+ 浏览器分析平台

历史 V1 说明：当前保留入口为 https://geocimplus.com/v1.html ，主域名已是 V2。版本对比及阅读顺序见 [阅读指南](V1与V2对比及ChatGPT阅读指南.md)。

访问 https://geocimplus.com/ 。顶部切换中文 / English；项目下拉默认沙头预设，导入后才显示「我的数据」。模型建构器位于顶部 Circuit，分析工作台下拉切换基础分析和 GeoCIMai 本地对话。无需注册，不使用模型 API，不产生模型调用费用。

## 使用自己的数据

1. 点击「导入本地数据」，选择文件，点击「导入到我的数据」。
2. GeoJSON 使用 WGS84 经纬度；Shapefile 同时选择同名 shp、shx、dbf、prj，或打包为一个 ZIP。程序按 PRJ 转为 WGS84；中文乱码时重新导入并选择 GBK / GB18030。
3. 在「属性表」选择字段、条件并选中要素，或逐行勾选。图层与选中要素的透明度分别调整。
4. 在「分析」选择输入图层、工具、全部或已选范围，然后运行。结果会成为新图层；字段统计显示在面板中。
5. 在「图层」下载结果 GeoJSON 与分析参数，或移除图层；地图工具栏导出 1920×1080 PNG。

个人文件和分析结果只存在当前网页内存中，不会上传服务器，不会被其他访客看见。刷新或关闭页面即清除。下载后可再次导入。沙头 Demo 的公开数据会在刷新时重新加载。

## 当前分析工具

| 工具 | 结果与定义 |
| --- | --- |
| 字段统计 | 记录数、有效数值、空值、非数值、总和、均值、极值、中位数；数字字符串可以参与统计 |
| 面积与长度 | 面积 m²、线长 m，使用球面测地公式，生成新字段并保留原属性 |
| 缓冲区 | 输入距离为米；每个要素独立生成，重叠部分不合并 |
| 生成代表点 | 几何顶点平均位置；凹多边形的结果可能位于面外，不等于人口分配 |
| 点核密度 | 仅 Point / MultiPoint；高斯核、3 倍带宽径向截断并归一化、本地等距方位投影，单位点数或权重/km²；无研究区边缘校正 |
| GeoTIFF | 读取地理定位；第一波段灰度预览、排除 NoData 的采样最小值 / 最大值 / 均值；不是 RGB 合成或全分辨率栅格计算 |

点核密度默认每点权重 1，也可指定全为非负数值且没有空值的权重字段。MultiPoint 的每个点使用同一个要素权重。面数据需要用户显式生成代表点后再运行；不可将其当作准确的人口位置。

自有面图层可在图层面板指定三维高度字段；请确认它是以米为单位的离地高度。空值显示为零，不推测年份或其他缺失属性。

## 当前处理规模

- 单次导入总计 64 MiB，最多 512 文件、12 图层；单个工作空间最多 20 图层。
- ZIP 解压声明总量最多 128 MiB，拒绝重复路径与目录穿越；只读取 Shapefile 配套文件。
- 矢量每层 100,000 要素、500,000 坐标位置、128 属性字段；只接受简单属性值。
- GeoTIFF 最多 1600 万源像元、预计解码量 128 MiB；最长预览边约 1024 像素。支持正北朝上 WGS84 经纬度、Web Mercator、WGS84 UTM；其他坐标系或旋转栅格先转换。
- 缓冲区最多 2000 要素、距离 0–5000 米（不含零）。代表点、缓冲区和核密度限定约 2 度区域并避开极区和日期变更线。
- 核密度最多 10,000 点、20,000 网格，并有计算量上限；带宽 10–5000 米，格网 5 米至带宽。
- 分析与导入在 Web Worker 内执行，可取消；90 秒未完成会终止。性能取决于访客电脑。

超过规模时先在桌面 GIS 中裁剪、简化或降低分辨率。原始文件始终不被改写。平台当前不提供云端长期保存、用户账号、共享私有数据或任意脚本执行。

## 沙头 Demo 数据

5306 栋建筑、124 条路网、178 个人口网格、1 个边界和卫星灰度预览。高度为用户确认的米制离地高度；人口 usum 为人数，单期 2019-04-28 09:10。缺少建成年份，因此没有年代分析。卫星 RGB 顺序、测绘级绝对定位精度仍未验证，详情见本机数据体检报告。
